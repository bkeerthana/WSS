# Topic 02: Variables and Data Types

## Learning goals
- Declare variables using `let` and constants using `const`.
- Understand basic JS data types (string, number, boolean, undefined, null).
- Use `typeof` to check a value's type.

## What students should do
1. Open `starter.js` and complete the TODOs.
2. Run:

```bash
node starter.js
```

3. Compare your output with `answer.js`.
