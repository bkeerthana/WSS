# Topic 04: Conditional Statements (if / else if / else)

## Learning goals
- Use `if`, `else if`, and `else` to implement decision logic.
- Validate input ranges before making decisions.

## What students should do
1. Set different values for `marks` in `starter.js` and observe outputs.
2. Complete the TODOs.
3. Run:

```bash
node starter.js
```
