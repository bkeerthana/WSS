# Topic 03: Scope (let, const, var)

## Learning goals
- Understand block scope for `let` and `const`.
- Understand function/global scope behavior of `var`.

## What students should do
1. Complete `starter.js` step-by-step.
2. Run:

```bash
node starter.js
```

## Notes for instructors
- Students should uncomment the lines in the order mentioned to observe errors intentionally.
