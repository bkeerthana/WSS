# JavaScript Assignments Pack (Student Version)

This pack contains 8 JavaScript assignments from basic to introductory DOM and browser storage.

Each folder includes:
- `index.html`
- `script.js` (TODOs)
- `README.md` (step-by-step instructions)

## How to run
1. Open the folder.
2. Double-click `index.html` to open in a browser.
3. Open Developer Tools (Console) when required.

## Included assignments
1. Variables + Console
2. Functions, Conditions, Loops
3. Arrays
4. Objects and JSON-like data
5. DOM selection + update
6. Events: Simple calculator
7. Form validation (client-side)
8. localStorage Notes app
