# Exercise 5: Semantic HTML

## Objective
Practice semantic HTML tags to structure a webpage.

## Theme
"Introduction to Cybersecurity"

## Steps
1. Set the title to "Semantic HTML".
2. Use these semantic elements:
   - `<header>`
   - `<nav>`
   - `<section>`
   - `<article>`
   - `<footer>`
3. Create a navigation bar with 3 internal links (anchor links).
4. Create at least two sections, each containing one article.
5. Add a footer with your name and year.

## Constraints
- HTML only (no CSS required).
- Use meaningful headings within sections/articles.
