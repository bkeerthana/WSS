# HTML Assignments Pack (Student Version)

This zip contains 6 HTML assignments. Each assignment folder includes:
- `exercise.html` (skeleton with TODOs)
- `README.md` (step-by-step instructions)

## How to use
1. Open any assignment folder.
2. Read `README.md`.
3. Complete the TODOs in `exercise.html`.
4. Validate output by opening the HTML file in a browser.

## Included assignments
1. Basic HTML Structure
2. Lists and Formatting
3. Tables
4. Forms (No Backend)
5. Semantic HTML
6. Cybersecurity-Themed Webpage
