# Exercise 2: Lists and Formatting

## Objective
Practice using lists and basic formatting tags in HTML.

## Steps
1. Set the title to "Lists and Formatting".
2. Add an H1 heading: "My Skill Set".
3. Create an unordered list (`ul`) of at least 5 technical skills.
4. Create an ordered list (`ol`) of at least 3 learning goals.
5. In any paragraph, highlight:
   - One key term using `<strong>`
   - One key term using `<em>`
6. Use `<hr>` to separate the "Skills" section and the "Goals" section.

## Constraints
- HTML only (no CSS/JS).
