# Exercise 4: Forms (No Backend)

## Objective
Design a simple HTML form using common input elements.

## Steps
1. Set the title to "Registration Form".
2. Add an H1 heading: "Student Registration Form".
3. Create a form that includes:
   - Name (text input)
   - Email (email input)
   - Gender (radio buttons: Male/Female/Other)
   - Course (dropdown/select with at least 4 options)
   - Terms and Conditions (checkbox)
4. Add:
   - Submit button
   - Reset button

## Constraints
- HTML only (no JS validation required).
- Use proper labels for inputs (`label` tag).
