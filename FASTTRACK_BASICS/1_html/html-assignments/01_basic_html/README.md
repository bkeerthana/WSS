# Exercise 1: Basic HTML

## Objective
Create a simple HTML page with a title, a headline, two paragraphs, and a link.

## Files
Use the skeleton in `exercise.html`.

## Steps
1. Set the title of the page to "My First HTML Page".
2. Add a level-1 headline (`h1`) with your name.
3. Add a paragraph describing your department.
4. Add a paragraph describing your area of interest.
5. Add a link to your institute website using the `<a>` tag.

## Constraints
- HTML only (no CSS/JS).
- Page must be valid HTML.
